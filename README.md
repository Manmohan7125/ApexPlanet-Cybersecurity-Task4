# ApexPlanet Cybersecurity Internship – Task 4

## Exploitation & System Security

This repository contains my work for **Task 4: Exploitation & System Security** of the ApexPlanet Software Pvt. Ltd. Cybersecurity & Ethical Hacking Internship.

## Objective

To understand the penetration-testing workflow and responsibly demonstrate exploitation, post-exploitation, password-security testing, security-awareness simulation, malware-analysis basics, and system hardening in an authorized lab.

## Lab Environment

- Kali Linux – testing machine
- Metasploitable2 – intentionally vulnerable target
- Private/isolated lab network
- Tools: Metasploit Framework, Hydra, John the Ripper and standard Linux security tools

## Activities

### 1. Penetration Testing Methodology
Reconnaissance → Scanning → Exploitation → Post-Exploitation → Reporting.

### 2. Exploitation with Metasploit
A known vulnerability was studied/exploited against the authorized Metasploitable2 lab target. Post-exploitation information was documented.

See: `Metasploit-Exploitation.md`

### 3. Password Attacks
Controlled SSH password testing with Hydra and authorized hash analysis with John the Ripper were documented.

See: `Password-Attacks.md`

### 4. Social Engineering Simulation
A phishing-awareness simulation was prepared for educational purposes only.

See: `Phishing-Simulation.md`

### 5. Malware Basics
Static and dynamic analysis concepts were studied using a benign sample in a sandbox/controlled environment.

See: `Malware-Analysis.md`

### 6. System Hardening
Security patches, firewall controls and disabling unnecessary services were reviewed/applied in the lab.

See: `System-Hardening.md`
